## A1.2 语义验证（本次修订的核心依据）

### 观察到的三组数字

在同样的 8 个 cal 窗口、同一 pinned checkpoint 下，对边 (15,2)：

| 构造 | block 15 的输入偏离真链 | block 16 的状态偏离真链 | 最终 ΔNLL |
|---|---:|---:|---:|
| Stage 2 执行器 `dag_forward`（`merge_mode="materialized"`） | 0.992 | **0.042** | **+0.056** |
| Stage 2 执行器 `merge_mode="roadmap"` | 0.992 | 0.042 | +0.057 |
| 同上但 `refine=False`（关掉串行续接捷径） | 0.992 | 0.042 | — |
| **持续传播**：x₁₅ := x₁₅ − Δ₂，后续 block 全部接着跑 | 0.992 | **0.991** | **+1.497** |

（"偏离"= 相对 RMS；均为逐样本均值。）

### 代数解释（可核对，非拟合）

设 `P_i` 为读者 i 的前驱集，`x_i = h0 + Σ_{j∈P_i} Δ_j`（执行器语义）。
删边 (15,2) 令 `P_15 = {0..14} \ {2}`，于是 **block 15 的输入**缺 Δ₂。

关键在于**下一个读者**：执行器在 block 16 重建输入时用的是 `P_16 = {0..15}`，**其中仍然包含 2**。
于是

```
x_16 = h0 + Σ_{j∈P_16} Δ_j = (h0 + Σ_{j≤14} Δ_j) + Δ_15' = out_14 + Δ_15'
```

其中 `Δ_15'` 是**被扰动过的** block 15 的残差更新。数值核对：执行器的 `x_16` 与
`out_14 + Δ_15'` 的相对 RMS 差 = **0.0017**（roadmap 为 0.0029），即该代数式**精确成立**。

**因此：Stage 2 的删边语义下，缺失的 Δ_j 并不向下游持续；它在下一个合并点被代数地重新注入。**
下游残差流的最终偏离，**只等于 block 15 自身更新 Δ₁₅ 的改变量**，而不等于被移除的 Δ₂。
这就是"block 15 的输入偏离 99%，而 block 16 的状态只偏离 4.2%"的来源。

### 这推翻了预注册的哪一条

预注册 §5 闸门 2 把这种差异归因为"Stage 2 用的是 materialized merge，本轮用的是『教师 x_i 减 Δ_j』，两者有已知的 bf16 合并舍入差"。
**该归因错误**：差异不是舍入差（舍入差是 1e-3 量级），而是**语义差**（差 24 倍）。

### 这与审计文档的哪一条一致

与第一轮审计的核心结论一致：
`h_final = h0 + Σ Δ_i` 恒成立且系数全为 1 ⇒ **删边只是把 Δ_j 在读者 x_i 内的系数置零，
Δ_j 仍以系数 1 到达 logits**。语义验证为这条代数结论提供了**直接的数值证据**。

## A1.3 修订：两种语义都测，分开报告

| 名称 | 定义 | 角色 |
|---|---|---|
| **S-PERSIST**（主） | x_i := x_i − Δ_j，随后**未改动的** block i+1..27 全部接在这个被扰动的状态上跑，Δ_j **永不回来** | **主语义**，对应任务书"让扰动继续经过后续原始 Block，观察变化是否被放大或消除" |
| **S-STAGE2**（对照） | 仓库执行器 `scripts/dag_exec.py` 的 `merge_mode="materialized"` 语义：读者 i 缺 Δ_j，但读者 i+1 的前驱集仍含 j，Δ_j 被代数重注入 | **对照**，即 Stage 2.1 数字的真正含义 |

两者**不混用**：所有子模块级读出属于 S-PERSIST；S-STAGE2 只给出状态级轨迹与端到端指标，
并且**直接调用仓库执行器**（`dag_forward`），不重新实现。

> 这样安排的理由：任务书要求"让扰动继续经过后续原始 Block"。持续传播才是"缺失的信息真的没了"的反事实；
> 而 S-STAGE2 是"删边改造"在工程上的真实语义。二者差异本身就是本轮最重要的机制发现之一，
> 因此必须同时测量而不是二选一。

## A1.5 指标定义的明确化（预注册 §4 只写了名字，此处补齐）

对读出点 o（教师值 o，扰动值 o′）与输入扰动 δ（逐 token）：

- **绝对变化**：`abs_change_mean = mean_t ‖o′(t) − o(t)‖`
- **相对变化**：`rel_change_mean = mean_t ‖o′(t) − o(t)‖ / ‖o(t)‖`，
  **分母守卫**：若 `‖o(t)‖ < 1e-3 × median_s ‖o(t)‖`（s 为同一样本同一读出点），该 token 被排除，
  同时报告被排除 token 数与中位数分母；被排除时相对变化记 n/a。
- **响应增益（绝对）**：`response_gain_abs = mean_t ‖o′(t) − o(t)‖ / ‖δ(t)‖`
  ——"每单位输入扰动产生多少输出变化"。
- **响应增益（相对）**：`response_gain_rel = rel_change_mean / mean_t(‖δ(t)‖/‖x_i(t)‖)`
  ——无量纲，可跨读出点、跨条件比较，是 P5a（径向 vs 切向）的判据。
- **方向变化**：`cos_pert_base_mean = mean_t cos(o′(t), o(t))`。
- **尺度口径**：所有相对量同时给出 **逐 token 口径**（mean/median/p90）与 **rms 加权口径**
  （`rms(num)/rms(den)`）。二者在本模型上**相差可达一个数量级**（见 A1.6），必须分开报告。

### bf16 存储地板（新增说明）

被扰动的输入按 bf16 存回（与真实残差流同精度）。bf16 的 1 ULP ≈ 2⁻⁸，
故**任何**扰动都附带一个与方向无关的 O(2⁻⁸) ≈ 0.2% 的相对扰动地板。
它对所有条件同向同量，因此：
- 条件之间的**比较**不受影响；
- 但对 η = 1% 的小扰动条件，**绝对**变化量有约 0.1%（rms 口径）的地板，
  解读小扰动条件时必须扣除该地板。

## A1.6 语义验证阶段顺带取得的两项事实（记录在案；**未**用于选边或选条件）

### 事实 1：扰动的相对幅度不是 O(1)，而是 O(0.1)（逐 token 口径）

| 边 | 逐 token ‖Δ_j‖/‖x_i‖ 均值 | 中位数 | p90 | rms 加权 | rms/逐token均值 |
|---|---:|---:|---:|---:|---:|
| (15,2) | 0.112 | 0.105 | 0.138 | **0.993** | 8.9× |
| (16,1) | 0.089 | 0.086 | 0.112 | 0.012 | 0.14× |
| (15,4) | 0.163 | 0.158 | 0.204 | 0.020 | 0.12× |
| (16,15) | 0.306 | 0.302 | 0.360 | 0.041 | 0.14× |

(15,2) 的 rms 加权比值 0.99 是 **BOS 位置（第 0 个 token）** 主导的假象：
该位置的逐 token 比值恰好 = 1.000，其余 token 均在 0.07–0.20 区间。
**预注册 P8 的"η 可能是 O(1)"的告诫在逐 token 口径下不成立**（实际 ≈ 0.11），
但**在 rms 口径下成立**（0.99）。两个口径都必须报告，这也是 A1.5 的要求。

### 事实 2：Δ_j 相对 x_i 的几何——既非纯径向也非纯切向，但显著正对齐

| 边 | cos(Δ_j, x̂_i) 均值 | 径向占比（幅度） | 径向分量/‖x_i‖ |
|---|---:|---:|---:|
| (15,2) | 0.322 | 0.324 | −0.038 |
| (16,1) | 0.422 | 0.422 | −0.037 |
| (15,4) | 0.292 | 0.293 | −0.048 |
| (16,15) | 0.479 | 0.479 | −0.147 |

即：真实缺失的更新**同时**含有显著的径向（尺度）成分与更大的切向（方向）成分。
这与预注册 P6 的"既非纯径向也非纯切向"一致，并为 P6b 的方向选择性检验提供了基线。

## A2.2 一个运行后诊断（明确标记为**非预注册**、**探索性**）

`scripts/m1_pos0_diagnostic.py`，产出 `results/mech_m1/pos0_diagnostic.json` 与 `pos0_attribution.jsonl`。

- **触发原因**：预注册数据里出现一个预注册设计**无法解释**的反常——
  在同一个读者层（15）、**同一个随机方向**（同种子）下，
  以 `‖Δ_2(t)‖` 为逐 token 幅度时 `|Δr_attn|/‖r_attn‖ = 1.04`，
  以均匀相对幅度 0.112 时只有 `0.41`，而以 `‖Δ_4(t)‖` 为幅度（**更大**）时只有 `0.25`。
- **假设 H0**：该模型的残差流在 **position 0** 携带**巨激活**（massive activation），
  `‖x_15[0]‖` 约为 token 中位数的 130 倍，而 `Δ_2` 贡献了其中绝大部分；
  移除 `Δ_2` 等于摧毁 position 0 的 key/value，而每个位置都 attend 到 position 0。
- **检验**：只扰动 position 0 vs 只扰动其余 256 个 token（同样的 8 个窗口、同样 4 条边、同样冻结权重）。
- **结果**：H0 成立，且效应量极大（见主报告 §3）。**这解释了 P1 的反常，也顺带解释了 Stage 2.1 单边代价图的成因。**
- **定位声明**：这是**事后归因**，不是预注册检验；它**不用于**选择边、条件、样本或读出点；
  预注册的全部结论**不依赖**它。
