## 1. 记号与块的精确结构

单个 token 的块输入 `x ∈ R^1024`，`d = 1024`，`s(x) = mean(x²) = ‖x‖²/d`，`ε = 1e-6`。
`γ₁, γ₂ ∈ R^d` 为两个入口 RMSNorm 的可学习逐通道增益，`γ_q, γ_k` 为 head_dim=128 上的 QK-Norm 增益。

```
u   = γ₁ ⊙ x / √(s(x)+ε)                       LN₁
q,k,v = W_q u , W_k u , W_v u
q̃   = γ_q ⊙ q / √(s_q+ε_q)   （逐头，沿 head_dim）   QK-Norm，在 RoPE 之前
k̃   = γ_k ⊙ k / √(s_k+ε_k)
q̃',k̃' = RoPE(q̃),RoPE(k̃)  （base=1e6，non-traditional）
a   = SDPA(q̃',k̃',v)  （causal，scale=1/√128，GQA 16Q/8KV）
r_attn = W_o a
h   = x + r_attn                                  第一次残差相加
w   = γ₂ ⊙ h / √(s(h)+ε)                         LN₂
g,u₂ = W_gate w , W_up w
act = silu(g) ⊙ u₂
r_mlp = W_down act
out = h + r_mlp
Δ   = out − x = r_attn + r_mlp                   块的残差更新
```

**P0（链的代数恒等式）**：串行链中 `out_k = h_k + r_mlp,k`、`h_{k+1} = out_k`，故
`h_28 = h_0 + Σ_k Δ_k`（精确算术下）。这正是 Stage 2 执行器利用的恒等式，
也是"从 x_i 中移除 Δ_j"成为一个良定义反事实的前提。

## 2. 数学预期（先于任何测量）

### P1 径向扰动：注意力分支近乎不变

令 `x' = (1+α)x`。则

```
u' = c·u ,  c = (1+α)√(s+ε)/√((1+α)²s+ε) = 1 + O(ε/s)        ← γ 在比值中约掉
q' = c·q , k' = c·k , v' = c·v                                ← 线性投影
q̃' = d_q·q̃ ,  d_q = c√(s_q+ε_q)/√(c²s_q+ε_q) = 1 + O(ε_q/s_q)
k̃' = d_k·k̃ ,  d_k = 1 + O(ε_k/s_k)
```

RoPE 是旋转，与均匀缩放可交换；注意力 logits 因此只乘 `d_q·d_k = 1 + O(ε/s)`。
**softmax 权重变化 O(ε/s)：注意力图样被冻结。**
于是 `a' = c·a`，`r_attn' = c·r_attn`：

> **P1a**：`|Δr_attn| / ‖r_attn‖ = O(ε/s)`。取 ε=1e-6，最小尺度层 s≈7.3e-4 时 ≤7e-4，中层 s=O(1) 时 ≤1e-6。
> **P1b**：径向扰动**不改变"哪个 token 注意哪个 token"**（到 O(ε/s)）。

### P2 残差旁路破坏块级的尺度等变性

`h' = (1+α)x + c·r_attn`，而 `c ≈ 1 ≠ 1+α`。于是

```
h' ≈ (1+α)·( h − α·r_attn )
```

- **方向**：h 在 r_attn 方向上的分量被压缩 α ⇒ 夹角
  `θ(h,h') ≈ α·‖r_attn,⊥‖/‖h‖`，记 `ρ = ‖r_attn,⊥‖/‖h‖`；
- **幅度**：`‖h'‖/‖h‖ = 1 + α(1 − cos(h,r_attn)) + O(α²) = 1 + O(α·ρ²)`。

> **P2a**：**RMSNorm 的近似不变性只作用于分支输入，不作用于整个块。** 旁路把未经归一化的 x 原样带回，因此块对输入的纯缩放**不是对称性**。
> **P2b**：径向扰动对 h 的**幅度**影响是二阶的（O(αρ²)），对 h 的**方向**影响是一阶的（O(αρ)）。

### P3 径向扰动只通过旁路诱发的旋转抵达 MLP

h 的方向移动 `O(αρ)`、幅度移动 `O(αρ²)`，而 LN₂ 消掉幅度 ⇒

> **P3a**：`LN₂` 输出的相对变化 `O(α·ρ)`；`r_mlp` 的相对变化 `O(α·ρ)`。

### P4 切向扰动：全程满量级，且注意力图样会动

`x' = x + δ`，`δ ⊥ x`，`‖δ‖ = η‖x‖`：

```
u' = u + γ₁⊙δ/√(s+ε) + O(η²)          ← 分支输入变化满量级 η
```

注意力 logits 变化 `O(η·ℓ)`（ℓ 为典型 logit 尺度），softmax 图样变化 `O(η·ℓ)`。
在 η=1%、ℓ=O(1..10) 时这是 **O(1–10%) 的图样变化**——与径向情形（冻结在 O(ε/s)）
**定性不同**。

> **P4a**：`|Δr_attn|/‖r_attn‖ = O(η)`；`|ΔLN₂|/‖LN₂‖ = O(η)`；`|Δr_mlp|/‖r_mlp‖ = O(η)`。

### P5 预测表（同为相对大小 η 的扰动）

| 读出点 | 径向 | 切向 |
|---|---|---|
| LN₁ 输出 | O(ε/s) | O(η) |
| r_attn | O(ε/s) | O(η) |
| 注意力图样 | O(ε/s) | O(η·ℓ) |
| h（方向） | O(η·ρ) | O(η) |
| h（幅度） | O(η·ρ²) | O(η) |
| LN₂ 输出 | O(η·ρ) | O(η) |
| r_mlp | O(η·ρ) | O(η) |
| Δ = r_attn + r_mlp | O(η·ρ) | O(η) |

> **P5a**：**同等相对大小的径向扰动应比切向扰动轻约 ρ 倍**（中层的 ‖r_attn‖/‖h‖ 实测量级为 2–5%，即约 1/20–1/50）。
> **P5b**：径向扰动主要改变 h 的**方向**而非幅度；切向扰动两者都改。

### P6 真实的 −Δ_j 既非纯径向也非纯切向

把 Δ_j 相对 x_i 分解为 `a·x̂ + δ_⊥`。径向部分按 P3 被衰减 ρ，切向部分不被衰减。

> **P6a**：真实 −Δ_j 的伤害应由它**相对 x_i 的切向分量占比**与 ‖Δ_j‖ 共同决定。
> **P6b**：在同范数控制中，**切向控制应最有害、径向控制最无害**；真实 −Δ_j 应按其实测切向占比落在两者之间。

### P7 幅度相关 vs 方向选择性（本轮的头号检验）

> **P7a**：若 `ΔNLL(real) > ΔNLL(matched_rand)` ⇒ **存在方向选择性**，真实 Δ_j 的方向（相对于残差几何）本身携带信息。
> **P7b**：若 `ΔNLL(real) ≈ ΔNLL(matched_rand)` ⇒ Stage 2.1 的边代价**只是被移除贡献幅度的函数**，方向无关。

### P8 大扰动的告诫

对 (15,2)，Stage 1 实测 ‖Δ_2‖ = 19.073（邻居仅 0.178 / 0.251）。其相对大小
η = ‖Δ_2‖/‖x_15‖ 可能是 O(1)，此时 P1–P5 的**线性**预期不适用，响应是**割线**而非切线。
故必须包含 η=1% 的小扰动对照集以取得干净的局部增益；**任何解读之前必须先报告实测相对扰动幅度**。

### P9 本轮**不能**说明的事

- 上述预期刻画的是**冻结模型的局部响应**；它们**不能**把响应归因于"RMSNorm 是成因"——归一化、投影权重、激活几何在冻结权重中纠缠，任何权重手术测的都是**另一个模型**；
- 它们**不能**证明任何依赖是"必要的"，只能说明模型在某个方向上局部敏感；
- 它们**不能**把单层/单窗口结果外推到其他模型或规模；
- 它们**不能**单独支撑项目级的"结题"或"继续"决定。

## 4. 干预与读出

**token 轴**：扰动**逐 token 定义、作用于整段序列**（与 Stage 2 的语义一致）。
单 token 变体本轮**不运行**，两种设置**不混用**。每个 token 独立构造其方向，

**7 个条件**（全部作用在同一个真实教师输入 x_i 上）：
