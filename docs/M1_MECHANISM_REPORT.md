## 0. 结论先行

本轮有**三个实质发现**，其中前两个改变了既有证据基础的解释：

1. **Stage 2.1 的"删边"干预不是"缺失上游更新"。** 删除边 (i, j) 后，Δ_j 会在**下一个合并点被代数地重新注入**，
   所以下游状态并不持续缺 Δ_j。Stage 2.1 的单边代价因此测量的是
   *"block i 对缺少 Δ_j 的局部敏感度 + 它诱发的 Δ_i 改变量"*，
   **不是**"移除 Δ_j 会损失多少"。二者在数值上差 **24 倍**。

2. **这个模型的残差流由 position 0 的巨激活主导。** layer 2 在 position 0 写入一个范数 ≈6706 的更新
   （token 中位数的 **1258 倍**，其中 6656 集中在**单一通道 35**），
   从 layer 3 起该状态在残差流里几乎冻结（6705.88 → 6712.37，直到 layer 27）。
   P1 (15,2) 的全部端到端伤害中，**99.2% 来自 position 0 这一个 token**。

3. **RMSNorm 的径向/切向不对称被证实（≥75 倍），但只在"同幅度大扰动"这一档可测。**
   在 η=1% 档，bf16 存储地板（≈0.1–0.3%）盖过了径向响应本身，
   因此预注册 P1a 的"径向响应 = O(ε/s)"**未被直接测到**，只能给出下界。

**对 Stage 2.1 的直接后果**：那条"大幅度残差 ↔ 高损失"的关系，
既不是单纯的幅度相关（读者输入处的相对幅度完全排不出 Stage 2.1 的排序），
也不是方向选择性（真实方向只比同范数随机方向高 1.16–1.47 倍），
而是**一个 token 层面的几何效应**——rms 口径下的"幅度"本就是 position 0 巨激活的代理量。

## 2. 发现一：Stage 2.1 的删边干预会自我抵消

### 2.1 两种语义

任务书要求"让扰动继续经过后续原始 Block"，这对应 **S-PERSIST**：x_i := x_i − Δ_j，
被扰动的状态一路穿过未改动的 block i+1..27，**Δ_j 永不回来**。
Stage 2.1 实际用的是仓库执行器 `scripts/dag_exec.py` 的 `merge_mode="materialized"`，记为 **S-STAGE2**。

### 2.2 代数（可核对，非拟合）

执行器语义是 `x_i = h0 + Σ_{j∈P_i} Δ_j`。删边 (15,2) 使 `P_15 = {0..14} \ {2}`，
于是 **block 15 的输入**确实缺 Δ₂。但**下一个读者**的前驱集是 `P_16 = {0..15}`，**其中仍然包含 2**，于是

```
x_16 = h0 + Σ_{j∈P_16} Δ_j = (h0 + Σ_{j≤14} Δ_j) + Δ_15' = out_14 + Δ_15'
```

其中 Δ₁₅′ 是**被扰动过的** block 15 的残差更新。

**数值核对**（8 窗口均值，相对 RMS）：

| 量 | 值 |
|---|---|
| 执行器 x₁₆ 与代数预测 `out_14 + Δ_15′` 的差 | **0.0017**（roadmap 0.0029；`refine=False` 同量级） |
| block 15 输入相对真链的偏离 | 0.992 |
| block 16 状态相对真链的偏离（S-STAGE2） | **0.042** |
| block 16 状态相对真链的偏离（S-PERSIST） | **0.991** |

**即：Stage 2 的删边语义下，缺失的 Δ_j 在下游被重新注入，下游残差流的最终偏离只等于 block 15 自身更新 Δ₁₅ 的改变量。**

### 2.3 端到端代价的量级差

| 边 | 相对幅度 η | **S-PERSIST** ΔNLL | **S-STAGE2** ΔNLL | Stage 2.1 记录（32 样本） | 比值 |
|---|---:|---:|---:|---:|---:|
| P1 (15,2) | 0.112 | **+1.4973** | +0.0558 | +0.06985 | **26.8×** |
| C2 (16,15) | 0.306 | +0.0778 | +0.0323 | +0.04119 | 2.4× |
| C1 (15,4) | 0.163 | +0.0252 | +0.0016 | +0.00472 | 16.0× |
| P2 (16,1) | 0.089 | +0.0012 | −0.0014 | +0.00072 | — |

（教师 NLL ≈ 3.276。）

这与第一轮审计的代数结论一致：`h_final = h0 + Σ Δ_i` 恒成立且系数全为 1
⇒ **删边只是把 Δ_j 在读者 x_i 内的系数置零，Δ_j 仍以系数 1 到达 logits**。
本轮为这条结论提供了**直接的数值证据**。

## 3. 发现二：position 0 的巨激活是残差流的主结构

### 3.1 逐层证据（`results/mech_m1/pos0_diagnostic.json` → `layer_norms`）

| layer | ‖x[0]‖ / median_t ‖x[t]‖ | ‖Δ[0]‖ / median_t ‖Δ[t]‖ | 备注 |
|---:|---:|---:|---|
| 0 | 1.0 | 1.1 | 嵌入态，无巨激活 |
| 1 | 1.1 | 2.7 | |
| 2 | 1.5 | **1258** | **layer 2 写入巨激活** |
| 3 | **537** | 0.3 | 巨激活进入状态 |
| 4–15 | 423 → 132 | ≈0.3 | 相对占比随普通 token 范数增长而稀释 |
| 16–27 | 119 → 10.5 | 0.3 → **14.2** | layer 26/27 在 position 0 再次放大 |

绝对值（样本 0）：`‖Δ_2[0]‖ = 6705.94`，`‖x_3[0]‖ = 6705.88`，`‖x_15[0]‖ = 6706.14`，
普通 token 的 `‖x_15[t]‖` 中位数只有 50.4。
**通道分解**（`channel_decomposition`）：`x_15[0]` 与 `Δ_2[0]` 的 top-1 通道完全相同——
**通道 35，值 6656.00**，top-3 占总能量的 **99.92%**。

即：**layer 2 用一个通道写入了 6656，随后整个网络把这个数原样搬着走。**

### 3.2 归因测试（`pos0_attribution.jsonl`）

把真实扰动 −Δ_j 只施加在 position 0，或只施加在其余 256 个 token：

| 边 | 变体 | r_attn 相对变化 | Δ_new 相对变化 | **ΔNLL** |
|---|---|---:|---:|---:|
| P1 | **只扰动 position 0** | **1.4070** | 0.9626 | **+1.4728** |
| P1 | 只扰动其余 256 个 | 0.1880 | 0.2115 | **+0.0123** |
| C1 | 只扰动 position 0 | 0.0052 | 0.0085 | −0.0005 |
| C1 | 只扰动其余 256 个 | 0.2858 | 0.3207 | +0.0257 |
| C2 | 只扰动 position 0 | 0.0068 | 0.0077 | +0.0005 |
| C2 | 只扰动其余 256 个 | 0.5965 | 0.5022 | +0.0772 |
| P2 | 只扰动 position 0 | 0.0089 | 0.0085 | −0.0009 |
| P2 | 只扰动其余 256 个 | 0.1839 | 0.1382 | +0.0014 |

**P1 的端到端伤害有 99.2%（+1.4728 / +1.4851）来自 position 0 这一个 token。**
其余三条边几乎完全由非零位置贡献。

### 3.3 这解释了 §2 里那个反常

在**同一读者层（15）**、**同一随机方向**（同种子）下：

| 逐 token 幅度剖面 | η | r_attn 相对变化 |
|---|---:|---:|
| `‖Δ_2(t)‖`（P1） | 0.117 | **1.0410** |
| 均匀 0.112·‖x(t)‖ | 0.112 | 0.4106 |
| `‖Δ_4(t)‖`（C1，**更大**） | 0.169 | 0.2533 |

原因：Δ₂ 的逐 token 幅度里含一个 position-0 的巨型分量（6900，而普通 token 约 5.6），
这个分量**不是**被"随机方向"平均掉的一个普通 token 的贡献——它摧毁的是 position 0 的 key/value，
而**每个位置都 attend 到 position 0**，所以影响是全序列的。

## 6. 五个研究问题的回答

### 6.1 真实缺失的 Δ_j 是否比同范数随机方向更有害？

**局部：是，但幅度不大；端到端：只对"未饱和"的边成立。**

| 边 | r_attn 响应增益（real / matched_rand） | Δ_new 响应增益 | 端到端 ΔNLL（real / matched_rand） |
|---|---:|---:|---:|
| P1 | 12.94 / 8.82 = **1.47×** | 9.03 / 5.32 = 1.70× | +1.4973 / +1.4976 = **1.00×** |
| C2 | 1.95 / 1.42 = **1.37×** | 1.64 / 1.35 = 1.21× | +0.0778 / +0.0299 = **2.60×** |
| C1 | 1.76 / 1.51 = **1.16×** | 1.97 / 1.83 = 1.08× | +0.0252 / +0.0050 = **5.04×** |
| P2 | 2.05 / 1.49 = **1.38×** | 1.55 / 1.41 = 1.10× | +0.0012 / −0.0026 = 符号翻转 |

- **局部**：真实方向比同范数随机方向**系统性地更敏感 1.16–1.47 倍**（r_attn 增益）。这是真实的方向选择性，但很小。
- **端到端**：C1/C2 上真实方向明显更坏（5.0× / 2.6×）；**P1 上完全没有差别**（1.00×），
  因为 P1 已经饱和（ΔNLL +1.5，top-1 一致率跌到 0.44），端点指标失去了分辨力。
- ⚠️ **`matched_radial` 在 P1 上反而比 real 更坏**（+1.578 vs +1.497），
  这不是"径向更危险"，而是**端点饱和 + 径向扰动改变了 state 的尺度而非方向**的联合效应；
  本报告不把它解读成方向选择的证据。

### 6.2 差异最先在哪个子模块表现出来？

- **最早出现差异的环节是 LN₁**（它是输入的函数，必然如此）：其相对变化 ≈ 输入相对变化，
  增益 ≈ 1.0–1.26。达到"增益 ≥ 1"的最早读出点是 LN₁ 的样本比例：P1 8/8、C1 8/8、C2 7/8、P2 5/8
  （其余样本首次达到增益 ≥1 的点是 r_attn）。
- **第一个把扰动放大到超过输入量级的环节是 `r_attn`（注意力分支）**：
  η=1% 时增益 3.98（读者 15）/ 5.14（读者 16）；大扰动时 P1 达 **12.94**（r_attn 相对变化 1.449，即变化量超过自身范数）。
- **MLP 分支紧随其后但不是第一**：r_mlp 的相对变化在 P1 上（1.589）略高于 r_attn（1.449），
  但它的**输入** LN₂ 只变化 0.412，说明 MLP 的高敏感度部分来自 LN₂ 之后的非线性。
- **径向扰动是例外**：在**同幅度**的径向对照里，LN₁ / r_attn / h / LN₂ 的增益全部 < 1
  （0.03 / 0.12 / 0.91 / 0.81），**第一个真正放大点是 `r_mlp`（增益 7.30）**。
  ⇒ **径向扰动的"第一个受损环节"是 MLP，切向扰动的是 Attention。**
  （η=1% 档的径向对照首个增益 ≥1 的点落在 r_attn，但增益仅 1.19，贴着 bf16 地板，不构成真实的放大。）

### 6.3 后续传播是否改变了局部重要性排序？

**改变了。**

| 排序依据 | 排序 |
|---|---|
| 局部（reader 15/16 处 `Δ_new` 的响应增益，real） | **P1 (9.03) > C1 (1.97) > C2 (1.64) > P2 (1.55)** |
| 端到端（S-PERSIST ΔNLL） | **P1 (1.497) > C2 (0.078) > C1 (0.025) > P2 (0.001)** |
| 端到端（S-STAGE2 ΔNLL）= Stage 2.1 记录 | **P1 (0.056) > C2 (0.032) > C1 (0.002) > P2 (−0.001)** |

**C1 与 C2 的次序在传播后互换。** 而且**传播后的排序与 Stage 2.1 的排序一致**——
也就是说，Stage 2.1 记录的是"传播后"的排序，而它的语义却让缺失的更新在传播中自我抵消（§2）。
这两件事必须分开陈述：**"重要性排序"是传播后的产物，不能当成单块敏感度。**

### 6.4 Stage 2.1 的"大幅度残差 ↔ 高损失"是幅度相关还是方向选择性？

**两者都不是（在本轮测到的边与口径下）。真正的驱动因素是 token 级的几何。**

1. **单纯幅度解释不了。** 读者输入处的相对幅度排序是 C2 (0.306) > C1 (0.163) > **P1 (0.112)** > P2 (0.089)，
   而 Stage 2.1 代价排序是 P1 > C2 > C1 > P2。**幅度第三大的 P1 代价最大**，幅度差 2.7 倍就反序。
2. **方向选择性存在但很小**：真实方向只比同范数随机方向高 1.16–1.47 倍（§6.1），
   不可能把 P1（0.056）与 C2（0.032）拉开 100 倍。
3. **真正的原因**：rms 口径下的"‖Δ_j‖"**就是 position-0 巨激活的代理量**。
   P1 的 Δ₂ 含一个 6706 的 position-0 分量，其余 256 个 token 只有 ≈5.6。
   把这个分量拿掉，P1 的伤害掉到 +0.0123（§3.2）。
4. ⇒ **Stage 2.1 的 98 条单边代价图，在很大程度上测的是"Δ_j 有没有动到 position 0 的巨激活"，
   而不是"Δ_j 在残差流中占多大分量"。**
   这直接削弱了第一轮审计中"幅度真实但远不充分"（Spearman +0.724 / 分桶 +0.292）那条结论的**解释框架**：
   幅度与代价的相关仍在，但"幅度"这个自变量本身需要被重新定义。

### 6.5 结果是否带来新的计算依赖理解，还是只增加描述性数据？

**带来了新的理解，但对象与预期不同，而且它**降低**了既有证据的价值。**

**新的（且是机制性的）：**
- "删边"干预的语义被证实是自我抵消的（§2），这使 Stage 2.1 的整个代价图**不能**按字面解读为"上游更新的重要性"；
- 该模型的残差流由 position 0 的巨激活主导（layer 2 写入、layer 3 起冻结），这是一个**具体的、可检验的**结构事实；
- RMSNorm 的径向/切向不对称在同幅度大扰动档达 ≥75×（径向冻结注意力、切向满量级），且**径向扰动的第一个受损环节是 MLP**。

**没有得到的：**
- 没有任何关于**硬件执行依赖**（C 类）的新证据；
- 没有新的 DAG、没有加速结论、没有训练相关结论；
- 没有把 attention 的 softmax **图样**直接测出来（`r_attn` 只是代理）；
- 没有 γ 方向扰动（按任务书要求本轮不加）。

**结论**：这不是"多了一批描述性数据"，但它也**不是**一个新的计算依赖结构——
它是对**既有实验的解释框架**的一次实质性修正。

## 7. 本轮不能说明的事（必须随结论一起引用）

1. **不能**把任何结果外推到别的模型、别的规模、别的序列长度或解码（KV cache）设置。
2. **不能**说"任何依赖是必要的"；这里测的是冻结权重下的局部敏感度。
3. **不能**把径向/切向不对称归因于"RMSNorm 是成因"——γ、投影权重、激活几何在冻结权重里纠缠。
   §4.3 中 P2b 被推翻恰恰说明：把观测归到某一个算子上，需要的是代数而不是类比。
4. **不能**单独支撑项目级的"结题"或"继续"决定（沿用审计 C8 的结论）。
5. **端点在 P1 上已饱和**（ΔNLL +1.5、top-1 0.44），P1 的端到端方向比较没有分辨力。
6. **bf16 存储地板 ≈0.1–0.3%**（见 A1.5）压在 η=1% 档上；该档的**绝对**变化量不可直接解读，
   但条件之间的**比较**不受影响（所有条件同向同量）。
7. **position-0 归因是事后诊断**，非预注册；预注册结论不依赖它。
8. 8 个窗口、2 个读者层（15、16）、4 个贡献者（1、2、4、15）——样本外推没有依据。

## 8. 独立判断：结果是否足以提出下一个可证伪问题？

**是，足以提出一个——而且只有一个——值得做的、可证伪的下一个问题。但我建议不要自行开始。**

### 8.1 候选问题（可证伪，且不需要训练）

> **Q\***：Stage 2.1 的 98 条单边代价，能否被 **Δ_j 的 position-0 巨激活占比**
> （例如 `‖Δ_j[0]‖ / ‖Δ_j‖`，或"逐 token 中位范数 / rms 范数"之比）
> **比现用口径更好地预测**？如果不能，则"巨激活"解释被推翻，
> 我们必须回到"幅度 + 方向选择性"这条线。

- **可证伪性**：预测与否都可以被一个静态计算判掉。
- **成本**：只需 1 次 teacher 前向 + 既有 `results/stage2_1/search_single/search.json`；
  不训练、不下新模型、不改旧结果。
- **若为真**：Stage 2.1 的代价图得到一个简洁的机制解释，且第一轮审计里"幅度 ↔ 代价"那条相关
  变成"巨激活占比 ↔ 代价"，整条证据链需要重写。
- **若为假**：说明还有别的机制在起作用（例如真正的方向选择性），值得再想。

### 8.2 我的建议

1. **不建议**在用户与 ChatGPT 共同决定之前启动任何下一步。Q\* 虽小，但它会**改写**第一轮审计的
   若干条结论，属于"改结论"而非"加结论"，应当先商量。
2. **强烈建议先处理一件事**：第一轮审计中凡是**依赖** Stage 2.1 单边代价图的结论，
   现在都需要降级或重新解释（不是推翻——数据本身没变，变的是它的语义）。
   按 C8 的既定原则，这不能由单个实验自动决定，需要你们一起定。
3. **不建议**再开"多边、多读者、多条件"的扫描：§6.3 已经说明，局部排序与传播后排序会不一致，
   而排序主要由"是否触及 position 0 巨激活"决定，扩样本不会带来新的机制结构，只会带来更多描述性数据。
4. **不建议**回到"删边 ⇒ 缩短关键路径"的加速叙事：§2 已经说明删边在本执行器里对下游几乎无效，
   其代价表不能直接当加速收益表用。
