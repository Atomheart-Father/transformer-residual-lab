## §1 更正清单

### C1（撤回）原审计 §4.4 的代数错误

**原审计写的**：

> 当 ρ = 1 时：`幅度占比 = (1−cos)² / [(1−cos)² + (1−cos²)] = (1−cos)² / (1−cos)² = 1`

**这是错的。** 正确结果是

```
幅度占比 = (1−cosθ) / 2 ,   方向占比 = (1+cosθ)/2      (ρ = 1)
```

**连带被撤回的原审计论断**："那 4 个计划里『幅度占比』恒等于 1"、"『方向成分 99.8%–100%』是 ρ=1 的代数后果"。**这两句都不成立。**

**Stage 1.5 §6.2 的原始百分比全部正确**，复核如下：

| 计划 | ρ | cosθ | r | 报告"幅度占比" | 复核 (ρ−cosθ)²/r² | 复核 (1−cosθ)/2 |
|---|---:|---:|---:|---:|---:|---:|
| prefix0-g2 | 2.335 | 0.270 | 2.278 | 82.0% | 82.2% ✓ | 不适用（ρ≠1） |
| prefix3-g8 | 1.000 | 0.996 | 0.084 | 0.2% | 0.23% ✓ | 0.2% ✓ |
| prefix3-g4 | 1.000 | 0.999 | 0.037 | 0.0% | 0.07% ✓ | 0.05% ✓ |
| prefix3-g2 | 1.000 | 1.000 | 0.016 | 0.0% | 0% ✓ | 0% ✓ |
| prefix10-g4 | 1.000 | 0.998 | 0.059 | 0.1% | 0.12% ✓ | 0.1% ✓ |

**并且有一处比原审计更强、也必须记录的更正**：原审计沿用了报告的分解 `(ρ−cosθ)² + (1−cos²θ)`，但这个分解**不是误差向量相对教师方向的径向/切向分解**。真正的径向/切向分解是

```
径向分量² = (ρ·cosθ − 1)² ,   切向分量² = ρ²·(1 − cos²θ)
```

（两者之和同样等于 r²，只是归因不同。）**当 ρ = 1 时两种分解恰好重合**，所以 4 个 ρ=1 的计划没有问题；但 **prefix0-g2（ρ=2.335）的"幅度占比 82%"严重高估了径向份额**：

| prefix0-g2 | 报告标注 | 真实径向/切向分解 |
|---|---:|---:|
| 径向（幅度） | 82.0% | **(ρcosθ−1)²/r² = 2.6%** |
| 切向（方向） | 18.0% | **97.4%** |

**这与 Stage 1.5 自己的干预结果是一致的**：`oracle-norm`（只修幅度）让误差**变差**（8.919→10.508），`oracle-dir`（只修方向）回收 79%（8.919→1.901）。也就是说，**报告的百分比标签与报告自己的干预结论互相矛盾，正确的几何读法反而支持"方向主导"**。

**保留有效的几何观察**：Stage 1.5 的"误差几乎纯粹是方向成分"作为**描述**是成立的（五个计划的真实径向份额均 ≤ 2.6%）；**仍然不成立的是它的因果断言**（见 C2）。

### C2（降级）"RMSNorm 解释了方向主导"——数学内核成立，归因未被证明

**原审计说**："方向成分 99.8%–100% 属于同义反复，需要修正（D）"。**这个理由撤回**（见 C1：它不是同义反复）。**但等级不变，仍是 C**，理由换成正确的：

- RMSNorm 的**归一化部分**对径向扰动的相对增益是 `α√(s+ε)/√(α²s+ε) = 1 + O(ε/s)`、对切向扰动是 `1`（原审计 §4.1–§4.2 的推导正确，数值验证正确）；
- **逐通道 γ 不破坏对整体正尺度变化的近似不变性**（γ 在比值中约掉）——原审计 §4.1/§4.2 已正确写出，此处重申，因为 C3 会误用 γ；
- 但"因此方向主导的**成因**是 RMSNorm"这一步**从未被验证**：Stage 1.5 的分解是**描述性几何**，不是因果实验；同一张表也完全兼容"并行组更新共线/部分抵消"这一竞争解释（Stage 1.5 §5.2 的 38%–70% 重构上限、条件数 2.7→40.1 是它的定量指纹）。

**结论**：几何描述 → **B**；RMSNorm 因果归因 → **C**（维持）。

### C3（撤回）用 γ 的 RMS 当作"Block 敏感度"，并据此解释距离/位置效应

**原审计的越界处**：
1. §4.3 用 `input_layernorm` 的 γ 沿深度增长 ~100 倍（rms(γ) 0.19→19.7）作为"每层写入幅度不同"的依据；
2. §3.5 把"位置效应"归因于"读者敏感度由 γ_i 决定"；
3. §7.1 的 D1 把"γ 放大"当作可检验的机制。

**全部撤回。** 理由与新证据：

**(a) γ 的 RMS 不是 block 的敏感度。** 分支输入的逐通道增益由 `γ ⊙ W` 共同决定，且下游投影权重的模长会补偿 γ 的变化。**逐层静态估计（本次复核新增，假设分支输入各向同性）**：

| 代理量 | 与实测 ‖Δ_i‖ 的 Spearman（全 28 层） | Spearman（层 10–26） |
|---|---:|---:|
| `rms(γ₁)` 单独 | +0.820 | **+0.968** |
| 静态估计（含 γ×W_v/W_g/W_u/W_d 的投影感知版） | +0.803 | +0.941 |
| 静态估计的 MLP 分支 | +0.786 | — |

→ **投影感知版本并没有比"只看 γ"更好。** γ 只是一个**秩代理**，在窗口内与深度相关性好（+0.968），但**不是驱动量**。

**(b) 静态估计在早层完全失灵。** layer 2 的实测 ‖Δ_2‖ = **19.073**（全模型第二大），而 layer 1 = 0.178、layer 3 = 0.251。静态估计给出 layer 1/2/3 = 22.8 / 18.1 / 25.6（几乎相同）——**"实测/静态"比值在这三层分别是 0.008 / 1.06 / 0.010，即静态模型对 layer 2 的巨大更新完全视而不见**。任何只依赖权重、假设输入各向同性的估计都无法捕捉它（这与 Stage 1.8 测到的 h₃ 协方差首特征值 176,473 vs 第二 5.14 的 massive activation 现象一致）。

**(c) 因此 §3.5 的两因子模型必须降级为"两个待检验的候选因子"，而不是"由 γ 支撑的机制"。** 幅度因子的**前提本身已被既有数据验证**（见 §2），但 γ 与敏感度的关系**没有**。

### C4（撤回）D1 的因果设计里把"移除 RMSNorm 后的模型表现"当作原模型机制的证据

**原审计 D1 的 M1 消融**："把某层 `input_layernorm` 换成恒等映射（真自由运行的模型改造）……用来分离 M1"。**撤回。**

替换归一化算子会**改变模型函数**：得到的是一个**不同的模型**，其性能差异是关于**那个新模型**的，不能反推原模型中归一化的作用。这与"归一化吸收幅度"这一**局部敏感性命题**不是一回事。同理，"γ 放大"不是机制检验，它只是描述了输入的逐通道增益。

**可隔离 / 不可隔离的清单**（替换原审计 D1 的第 (2)(4) 项）：

| 独立变量 | 能否在冻结原模型内隔离 | 方法 |
|---|---|---|
| 扰动方向（径向 / 切向 / γ-高维对齐 / γ-低维对齐 / massive-activation 对齐） | **能**（完全可控） | 直接构造 δ |
| 扰动相对大小 | **能** | 缩放 δ |
| 被观测的读者层 | **能** | 逐层注入 |
| 被观测的子模块（attention half / MLP half / block 输出 Δ） | **能** | 逐点读出 |
| **"敏感度为什么是这个值"**（RMSNorm vs 权重几何 vs 激活协方差） | **不能** | 三者在冻结权重中纠缠；任何权重手术都换了函数 |
| **massive activation 对相对扰动显著性的影响** | **只能部分**（可用"沿 massive 维度 vs 沿非 massive 维度"两个方向对比，但两者仍同时改变 γ 对齐度） | 需正交化设计 |

### C5（撤回）D2 声称的"半段级并行"是新的并行结构

**核对 True Depth（arXiv 2502.02790v3）的 (LP) 公式**（附录 A.1 Eq.(6)(7) 与 §3）：

```
ũ  = x + A_k(x) + A_{k+1}(x)          ← 两个 attention half 在同一输入 x 处求值
T_LP(x) = ũ + F_k(ũ) + F_{k+1}(ũ)      ← 两个 FFN half 在同一中间态 ũ 处求值
```

**这正是原审计 §7.2 提出的"半段级并行"**：组内 k 个 block 的 attention half 共享同一 x 求值、MLP half 共享合并后的 h 求值。**原审计把它当作新发现，是错的——它是 True Depth 已发表的 (LP) 形式。** CQIL 的组执行在 p=2 时也是同一形式（另加 bypassing 回注 ATTN 输出）。

**因此 D2 从"候选机制实验"降级为"在 0.6B 上的规模复现"，而这不值得做**：

- True Depth 的加速来源是**张量并行下的同步次数减半**（附录 E：sync 100.8→50.7 ms，compute 217.0→208.7 ms）。**单卡没有同步可减**；
- FLOPs 不变，critical path 的 FLOPs 长度不变；单卡唯一可得的杠杆是 kernel 重叠，而 **Stage 2.1 Part A 已经实测了它的上限（独立块重叠 ≤1.46×，A5 证明"权重堆叠成一次大 matmul"在 n=1 时反而慢 29%）**；
- True Depth §6 自述 *"Smaller models show reduced benefits, likely due to their less sparse activation patterns and more tightly coupled layer dependencies."*——对 0.6B 是直接警告；
- **D2 撤回**，不作为实验保留。

### C6（降级）"拆分后逐 bit 不一致 = 发现新的计算依赖"

**原审计 §7.2** 把"C1 拆分后 logits 不逐位一致"称为"一条重要发现"。**降级为工程问题。** 逐 bit 差异的可能来源至少包括：MLX 的 kernel 融合与求和顺序、累加 dtype、mask/cache 处理路径——**这些都是我们重新实现的可复现性差异，不是关于模型依赖结构的发现**。原审计还把它列为"可能一次性推翻 block 原子性假设"——那需要**独立证据**（例如数学等价性证明或跨实现的数值一致性），而不是一次实现差异。

**结论**：C1 拆分检查仍应保留，但它是**实验前的数值卫生检查**（若不通过，先修实现，再谈机制），不承载机制结论。

### C7（修正）两处研究表述

**(a) Stage 2 的"删边"**：原审计 §3.4 说它"不是真实计算图里的依赖边"。**表述需要两头都写清楚**：

- ✅ 成立：它**不是原始模型中显式存在的任意跨层算子边**——Qwen3 的层轴是严格残差链，"边"是我们构造的**反事实干预**；
- ✅ 同样成立：被干预的对象是**真实存在的上游贡献 Δ_j**（它确实在残差流里、确实进入 h_final、确实以系数 1 到达 logits），干预方式是"在读者 x_i 内部把它的系数置零"。
- ⚠️ 因此正确表述是：**"对真实上游贡献的反事实干预"**，而不是"测量原模型层间依赖边的重要性"，也不是"什么都没测"。

**(b) token 轴 MLP 并行**：原审计 §9.1 Q6 把"MLP 分支严格逐 token"包装成"**几乎零改动的真实并行机会**"。**撤回"机会"这层说法**——常规 batched prefill 本来就把所有 token 一次性送进同一次 GEMM，**该并行性早已被实现利用**。剩下的正确表述只有结构性那一句：**Qwen3 的跨 token 依赖完全集中在注意力分支内部**，这是一个关于**依赖结构**的事实，不是关于**未开发算力**的机会。

### C8（撤回）两条不成立的结题规则

| 原审计 §9.1 Q7 的触发条件 | 判定 | 理由 |
|---|---|---|
| "D1 显示位置/距离效应可被幅度 + 读者增益两个标量因子完全解释 ⇒ 线关闭、结题" | **撤回** | 两个标量因子解释了一条**统计相关**，不等于真实层间机制已被解释。相关的因素可以共享同一个未观测的成因；反向也不成立——解释不了某个相关并不能证明机制未被理解。 |
| "D2 某一种半段并行没有收益 ⇒ 证明完整 Block 是最优原子单元" | **撤回** | (i) 半段并行已被 True Depth/CQIL 发表（见 C5），单一实现无收益只否证该实现；(ii) "没有找到更好的并行单元"不等于"当前单元是最优的"；(iii) 原本的 D2 已被撤回。 |

**替代的停止条件**（写入 §5）：实验只能**证伪一个被明确写下的定量模型**；它的任何结果都**不能**单独支撑项目级的"结题"或"继续"决定。

## §2 本次复核新增的证据（零模型运行）

原审计提出的"幅度 vs 方向""距离效应 vs 位置效应"两个假说，其**前提可以用仓库既有的原始数据直接检验**，不必跑模型。以下结果来自 `results/smoke/layer_summary.csv`（Stage 1 实测的逐层真实更新幅度 `teacher_delta_rms`，跨 group2/g4/g8 三种 plan **完全一致**，即与分组无关的教师态量）与 `results/stage2_0/full/screen.json`（位置效应）、`results/stage2_1/search_single/search.json`（98 条单边地图）。

**两条必须随读随引的限定**：

1. **测量上下文不同**。‖Δ_i‖ 来自 Stage 1 的 **129 token / 16 样本 / smoke 规模**测量；单边代价来自 Stage 2.1 的 **257 token / 32 样本 / 全 28 层**测量。幅度剖面已验证**与分组方式无关**，但**对窗口长度的依赖未验证**——把它当作跨阶段的代理是有代价的假设。
2. **Stage 2.1 的 98 条边的读者是 i ∈ [11,17]**（11+12+…+17 = 98），贡献者 j ∈ [0, i−1]；距离 d = i − j。原审计与旧报告在窗口边界上偶有 "10–17" 的口语说法，以此处为准。

### 2.1 逐层真实更新幅度 ‖Δ_i‖（Stage 1 实测）

| 层 | 0 | 1 | **2** | 3 | 4 | … | 10 | … | 16 | 17 | … | 26 | **27** |
|---|---:|---:|---:|---:|---:|---|---:|---|---:|---:|---|---:|---:|
| ‖Δ_i‖ | 0.274 | 0.178 | **19.073** | 0.251 | 0.277 | | 0.479 | | 0.910 | 1.099 | | 6.135 | **20.786** |

- **层 14–27 严格单调递增**（Spearman = **+1.000**）；全 28 层 Spearman(layer, ‖Δ‖) = **+0.826**；层 27 / 层 0 = **75.8×**。
- **层 2 是一个 100× 的孤立尖峰**（19.073，邻居只有 0.178 / 0.251）——这与 Stage 1.8 测到的 h₃ 协方差首特征值 176,473 vs 第二 5.14 的 massive activation 现象吻合。
- 早期层（0–13）**非单调**（Spearman +0.644）。

### 2.2 距离效应：幅度前提**成立**，但幅度不足以单独解释

Stage 2.1 的距离效应测于窗口 [10,18)。窗口内 ‖Δ_j‖：

```
j =   10     11     12     13     14     15     16     17
‖Δ‖ 0.479  0.519  0.394  0.402  0.489  0.564  0.910  1.099
```

- Spearman(j, ‖Δ_j‖) = **+0.738**（**非单调**：Δ_12 < Δ_11、Δ_13 < Δ_12）；近端/远端比 Δ_17/Δ_10 = **2.30×**。
- **对照**：实测的距离效应是 d=1 时 0.0360 nats → d=8 时 0.00873 nats（**4.12×**，与报告的 "0.036 → 0.0087" 一致）。
- **判读**：读者固定时，丢掉**更近**的贡献者确实意味着丢掉**更大**的 Δ（幅度前提成立）；但幅度只增长 **2.3×**，而实测 ΔNLL 变化 **4.12×**，**幅度解释不了全部**，需要第二个因子。
- **注意该效应并非单调**：d=9 回升到 0.01284、d=13 到 0.01662、d=15 到 0.01544。报告把这些概括成 "d≥8 后平在 0.004–0.008 的地板"，但 d=13/d=15 的桶**高于**该地板——这两桶的贡献者集合是 {0,1,2,3,4} 与 {0,1,2}，**都包含 layer 2**（Δ₂ = 19.07）。这是一个此前未被指出的细节，与幅度解释方向一致。

**并且两个离群点被幅度精确预测**（本次复核最醒目的一条）：

| 边 | 被移除的贡献 | 其 ‖Δ‖ | 实测代价（Stage 2.1 的 98 条地图） |
|---|---|---:|---:|
| (15, 2) | Δ₂ | **19.073（全模型第 2 大）** | **0.06985 nats —— 98 条里最贵** |
| (16, 1) | Δ₁ | **0.178（全模型最小）** | **0.00072 nats —— 98 条里最便宜** |

最贵的边对应幅度第 2 大的层，最便宜的边对应幅度最小的层——**两次独立测量在最极端处完全对上**。

**但必须立刻补上反面证据，否则这条会被过度使用。** 对全部 98 条边做直接检验：

| 检验 | 结果 |
|---|---|
| Spearman(逐边代价, ‖Δ_j‖) | **+0.724**（n=98）；排除贡献者 layer 2/27 后 +0.681 |
| Pearson(log 代价, log ‖Δ_j‖) | +0.511 |
| Spearman(距离分桶的平均代价, 平均幅度) | **仅 +0.292** |
| 最贵 8 条边的贡献者幅度排名 | 2, 13, 15, 15, 14, 17, 15, 2 —— **只有 2 条是幅度离群点** |

**判读（修正后的）**：幅度是一个**真实但远不充分**的因子。

- 它解释了**极端**：最贵与最便宜的两条边；
- 它**不解释分布**：98 条边的秩相关只有 +0.72，而最贵的 8 条里有 6 条其贡献者幅度排名在 13–17 之间（普通水平）；
- 它**不解释距离效应本身**：d=1→d=8 代价降 4.12×，而对应桶的平均幅度只降 1.70×（0.537→0.316）；且 d=9…d=15 的桶因为纳入 layer 2，平均幅度跳到 3–6.5，代价却停在 0.010–0.017。分桶相关只有 +0.292。

**因此本补遗撤回原审计 §2.2 初稿里"距离效应是幅度效应的影子"的确切说法**，改为：**幅度解释了位置/距离效应的极端与离群点，但不解释其分布；第二个因子是必需的。** 这条修正**加强**而非削弱 M1 的必要性（见 §3）。

### 2.3 位置效应：幅度解释**极端**，不解释**中间排序**

| 窗口（g2，漏掉每对的第一块） | 被漏掉的 Δ | 幅度之和 | 最大 | 窗口内 Σ‖Δ‖ | 实测 ΔNLL |

### 2.4 γ 的重新定位

| 命题 | 判定 | 依据 |
|---|---|---|

## §3 唯一保留的实验：M1 —— 冻结原模型内的局部敏感度剖面

> **不运行，只设计。** 需用户与 ChatGPT 批准后执行。

### 3.1 可证伪的问题

> 在**不改动任何权重、不替换任何算子**的前提下，Qwen3-0.6B 的每个 block 对其入口激活的**局部响应**是否呈现"径向增益 ≈ 0、切向增益 ≈ 1"的各向异性？
> - 若**是**：Stage 1.5 的"幅度被吸收、方向不被吸收"从 **C（假设）** 升到 **B（原模型内的因果证据）**；
> - 若**否**：该机制说法在原模型内**被证伪**，Stage 1.5 §6.2 的机制段必须撤回，只保留描述。

### 3.2 竞争解释（必须彼此可分）

| 代号 | 解释 | 判别信号 |
|---|---|---|
| **H1 归一化吸收** | RMSNorm 的归一化部分使径向扰动几乎不改变分支输出（增益 O(ε/s)），切向扰动以增益 ≈1 通过 | D1（径向）增益 ≈ 0；D2（切向）增益 ≈ 1 |
| **H2 γ 各向异性** | 响应由扰动方向与 γ 的对齐决定，与径向/切向无关 | D3（γ-高对齐）增益 ≫ D4（γ-低对齐）增益 |
| **H3 激活几何** | 响应由扰动是否落在被 massive activation 主导的子空间决定 | "massive 对齐"与"非 massive 对齐"在控制 γ 对齐后仍有差异 |
| **H4 饱和** | silu 门控或 softmax 饱和使响应与方向无关 | 响应增益在所有方向上近似相同 |

### 3.3 精确的干预目标

| 维度 | 目标 |
|---|---|
| op 节点 | 第 i 个 block 的**入口激活 x_i**（teacher-forced 链上的真实输入），i = 0..27 |
| 张量 | δ ∈ R^{B×L×1024}，相对大小固定 η（默认 1%） |
| 方向（5 条） | **D1** 径向 δ = η‖x_i‖·x̂；**D2** 切向 δ = η‖x_i‖·u（u ⊥ x_i，随机种子固定，抽 3 次取均值）；**D3** γ-高对齐（在 \|γ₁,i\| 最大的 64 维子空间内、与 x_i 正交化）；**D4** γ-低对齐（最小 64 维，同上正交化）；**D5** massive-对齐（x_i 逐元素范数最大的 64 维，正交化） |
| 子模块读出点 | ① LN₁(x) 输出；② r_attn = o_proj(attn)；③ h = x + r_attn；④ LN₂(h) 输出；⑤ r_mlp；⑥ Δ_i = out − x_i |
| layer 维 | 全 28 层，重点 10–17 |
| token 维 | 全部 L（257 token 窗口） |
| head / FFN 路径 | 16Q/8KV 全量；MLP 3072 全量 |

**全部在原模型、原权重、原执行顺序下进行**——不替换归一化算子、不缩放 γ、不重排层。

### 3.4 四类对照（不得混用）

| 代号 | 内容 | 用途 |
|---|---|---|
| **C0 基线** | η = 0 的注入（数值上应复现原模型） | 基准 |
| **C1 数值卫生** | 把 block 拆成 attention half / MLP half 两次调用再合并，与单次调用比较（允许 fp32 相对误差 ≤1e-3） | **只查我们自己的实现是否数值可靠**；不通过就先修实现。**不是机制证据**（C6） |
| **C2 局部读出** | 在 x_i 注入 δ，**只前向第 i 个 block**，读出 ①–⑥ | 给出**局部响应增益**，便宜、无下游污染 |
| **C3 自由运行传播** | 在 x_i 注入 δ，**重跑后缀 i+1..27**，测最终 ΔNLL / KL / top-1 | **唯一给出质量数字的类别**，必然叠加下游放大 |

**红线**：C2 的"响应小"**不得**直接当作 C3 的"质量损失小"；两栏分开报告。

### 3.5 观察指标

1. 每个 (层, 方向) 的**相对增益** g = ‖Δ_out(δ) − Δ_out(0)‖ / ‖Δ_out(0)‖，对 ①–⑥ 各算一次；
2. **逐通道响应**：LN₁ 输出对 δ 的逐通道相对变化（看 γ 对齐度是否决定增益，判 H2）；
3. **子模块归因**：r_attn 与 r_mlp 各自的响应（Stage 1 从未有过这个分解）；
4. **两因子模型检验**：把 C3 的逐层单边代价与
   `cost(j→i) ≈ (‖Δ_j‖ / ‖x_i‖) × G_i`（G_i 由 C2 测得）做回归，报告 Spearman 与 R² 及残差结构。
   **先验（本次复核已测）**：只用幅度因子时，逐边 Spearman = **+0.724**、分桶 = **+0.292**，最贵 8 条中 6 条的幅度贡献者普通 ⇒ **预期回归 R² 中等、残差有结构**。M1 要测的正是那个未测到的第二因子 G_i；**如果加进 G_i 后残差结构不消失，说明存在第三个因子**（见 R5）。
5. 复用既有量：‖x_i‖、‖Δ_i‖（Stage 1 `layer_summary.csv`）。

### 3.6 预期反例（能推翻的证据）

| 代号 | 反例 | 推翻什么 |
|---|---|---|
| **R1** | 某层实测**径向增益 > 0.05**（bf16 噪声地板 ~4e-3 的十余倍） | "RMSNorm 吸收幅度"在原模型内被证伪 → Stage 1.5 机制段降为 **D** |
| **R2** | D3/D4 的增益之比 ≈ 1 | **H2**（γ 各向异性） |
| **R3** | D2/D1 的增益之比在所有层都 ≈ 1 | **H1**（幅度被吸收） |
| **R4** | C2 的局部响应排序与 Stage 2.1 的 98 条边代价排序 Spearman ≈ 0 | **两因子模型**（读者敏感度因子解释不了实测代价分布） |
| **R5** | 控制 γ 对齐后，"massive 对齐"与"非 massive 对齐"仍有差异 | 存在**第三个未识别因子**（激活几何），两因子模型不完整 |

### 3.8 正负结果的价值

- **H1 被支持**（径向 ≈0、切向 ≈1，且 C3 中方向扰动的下游损失显著大于幅度扰动）：Stage 1.5 的机制归因**在原模型内**由 C 升到 B——这是本项目第一次拿到**不需要改任何权重**的因果证据；同时得到逐层敏感度表，可直接检验两因子模型。
- **H1 被证伪**（R1/R3）："方向主导"另有成因，Stage 1.5 §6.2 的机制段**必须撤回**、只留描述。这是明确的**降级性结论**，价值在于避免把错误机制写进论文。
- **两因子模型被证伪**（R4）：位置/距离效应的成因不在"幅度 + 读者敏感度"内，需另找维度——同样是**有价值的负结果**，因为它把下一步指向具体位置而不是"再找找"。
- **R5 成立**：等于记录了一个此前未被注意的因子（massive activation 的几何作用），本身是新发现。

### 3.9 本实验**不能**得出的结论（必须写进 preregistration）

1. **不能**证明或证伪"归一化是成因"——RMSNorm、权重几何、激活协方差在冻结权重中纠缠，无法隔离（C4）；
2. **不能**把单层/单窗口结果外推到其他模型或规模；
3. **不能**单独支撑项目级的"结题"或"继续"决定（C8）；
4. **不能**替代"真正从 h_final 移除 Δ_j"的信息流消融（那是另一个更强的干预，原审计 §3.4 已指出它从未被做过）；
5. **不能**把 C2 的局部读出当作可部署结果。
